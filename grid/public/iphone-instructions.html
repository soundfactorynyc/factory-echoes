GRID OS iPhone Access Instructions

Note: The server is currently running on port 5174. Make sure to use this port in all URLs.

Quick Access URLs

Use these URLs to access different parts of GRID OS:

http://192.168.1.250:5174/main.html

Main App: This is the main GRID OS interface with the grid visualization.

http://192.168.1.250:5174/redirect.html

Navigation Page: This page provides easy navigation to all parts of GRID OS.

http://192.168.1.250:5174/mobile-test.html

Mobile Test: A mobile-friendly interface for testing GRID OS features.

Step-by-Step Instructions

  1. Make sure your iPhone is connected to the same Wi-Fi network as the computer running the GRID OS server.
  2. Open Safari on your iPhone.
  3. Enter the URL for the Navigation Page: http://192.168.1.250:5174/redirect.html
  4. From the Navigation Page, you can easily access all parts of GRID OS.
  5. To go directly to the main app, use: http://192.168.1.250:5174/main.html
  6. Or use the navigation page to easily access all parts of GRID OS.

Troubleshooting

If you're having trouble accessing GRID OS:

  • Ensure your iPhone is connected to the same Wi-Fi network as the computer running the server.
  • Try using the IP address directly: 192.168.1.250:5174
  • If the page doesn't load, check if the server is still running on the computer.
  • Try clearing your browser cache or using a private/incognito browsing window.
